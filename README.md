Área de transferência mais organizada para Windows.

[Site oficial](https://algeritec.com.br)

## Instalação

Baixe o arquivo Setup.exe da release e execute o instalador. Windows de 64 bits.
A beta 2 habilita o atualizador: instale-a manualmente uma vez.

## Atualizações

O aplicativo verifica novas versões em segundo plano e avisa no próprio painel.
Em Configurações > Sobre, você também pode verificar e escolher Atualizar agora.
Os pacotes são assinados; o histórico e as preferências são salvos antes de instalar.

Este repositório contém somente informações de distribuição e instaladores.
O código-fonte é privado. O arquivo latest.json é consultado pelo aplicativo.
