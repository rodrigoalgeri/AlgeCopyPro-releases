[Site oficial](https://algeritec.com.br)

## Instalação

Baixe o arquivo Setup.exe da versão e execute o instalador. Requer Windows de 64 bits. O instalador oferece atalhos no menu Iniciar e na área de trabalho.

A partir da versão 1.0.1, o aplicativo inicia automaticamente ao entrar no Windows. Para desativar ou reativar, use **Configurações → Comportamento → Iniciar com o Windows**. Essa preferência é preservada nas atualizações.

## Atualizações

O aplicativo verifica novas versões em segundo plano e avisa no próprio painel. Em **Configurações → Sobre**, você também pode verificar e escolher **Atualizar agora**. Os pacotes são assinados para o atualizador; o histórico e as preferências são salvos antes de instalar.

Este repositório contém somente informações de distribuição e instaladores. O código-fonte é privado. O arquivo latest.json é consultado pelo aplicativo.
